Messages are stored as encrypted packages.

Message flow

  1. A fresh AES-256 key encrypts each message with AES-GCM.
  2. RSA-OAEP wraps the AES key for the recipient.
  3. The sender signs the encrypted package with RSA-PSS.
  4. The recipient verifies the signature, then chooses to decrypt.

SECURITY INFORMATION

            
About and security

          

          

            
Security notes

            
A valid signature shows that a message verifies under a particular public key. It does not prove the real-world identity of the person using that key. Trust is a separate user decision.

            
Private-key passwords protect key files at rest. They do not protect an unlocked key or a compromised computer.

            
The accounts and storage in this project are intended for local use. Do not use these demo credentials for other services.
